# 工作流程參考

此文件是按需參考，不是每次工作都必須套用的流程。

## 原則

- 先理解需求與現有內容；範圍明確的小任務直接處理。
- 使用者明確要求建立、修改、修復、執行或套用時，即視為該範圍的授權。
- 僅在資訊會影響正確性、範圍或風險時提問。
- 高風險或不可逆操作先說明影響並取得確認。

## 執行與驗證

- 優先採取最小且可審閱的變更。
- 變更後執行最接近受影響範圍的驗證；若無法執行，清楚說明原因。
- 驗證失敗時，先回報證據與下一步，不以修改測試或擴大範圍來掩蓋問題。

## 協作

- 專案內的 `AGENTS.md`、README 與貢獻文件優先於此文件。
- 只有工作確實需要額外專業或平行處理時才使用專門工具或子代理。
