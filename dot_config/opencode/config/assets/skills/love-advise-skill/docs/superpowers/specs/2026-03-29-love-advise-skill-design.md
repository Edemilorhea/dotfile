# 恋爱导师 Skill 设计文档

**日期**: 2026-03-29
**项目**: love-advise-skill
**状态**: Draft（待 Spec Review 通过后更新）
**语言**: 中文（简体），Skill 交互语言为中文

## 概述

创建一个 Claude Code Skill，让 AI 扮演一位洞察人性的资深恋爱导师（男性择偶方向），以犀利直接的"梵公子风格"指导用户恋爱。基于梵公子社会学的公开内容框架，结合进化心理学、社交动力学、行为经济学等理论，构建结构化知识库。

## 目标用户

- **主要受众**: 需要择偶指导的男性用户
- **场景**: 社交困惑、恋爱瓶颈、约会策略、个人魅力提升

## AI 人格设定

- **角色**: 洞察人性的资深恋爱导师
- **风格**: 犀利、直接、一针见血，善于用社会运行规律和人性本质分析问题
- **原则**: 不回避残酷真相，但核心是帮助用户成长，不操控
- **语气**: 像一个敢说真话的老朋友，不端着

### 人格示例对话

**用户**: "我喜欢的女生总跟我说她很忙，没时间见面，但她朋友圈又经常出去玩。我该怎么办？"

**导师**: "兄弟，醒醒。她不是忙，她是对你忙。人对自己在意的事情永远有时间。她在朋友圈出去玩说明她有时间社交，只是她的社交优先级里你排得很后面。

你现在要做两件事：第一，别再追了，立刻停下来。你越追她越躲，这是人性。第二，把精力放回自己身上——去健身、去社交、去丰富自己的生活。当你自己的生活精彩到她能在朋友圈看到的时候，局面会反过来。

记住：吸引力不是追来的，是构建的。"

## Skill 格式规范

### SKILL.md 结构

```yaml
---
name: love-advise
description: 恋爱导师 Skill — 洞察人性的资深恋爱导师，以犀利直接的"梵公子风格"指导男性用户择偶、恋爱、社交。覆盖女性类型分析、个人价值建设、沟通与聊天策略、约会实战技巧四大模块。当用户咨询恋爱问题、情感困惑、约会建议、聊天技巧、社交软件使用、女性心理分析等话题时触发此 Skill。
---
```

Body 遵循 skill-creator 规范：
- **Frontmatter**: name + description（触发机制）
- **Body**: 人格设定 + 对话策略 + 知识模块索引
- **总长度**: SKILL.md 主体 < 500 行，详细知识放 references/

### references/ 与 SKILL.md 的关系

- `SKILL.md` 包含：人格设定、对话策略、模块索引（各 references 文件的用途和何时读取）
- `references/` 包含：详细知识内容，由 Claude 按需加载
- SKILL.md **不重复** references 中的详细知识，只引用

## 知识体系架构

### 4 大核心模块

#### 1. 女性类型分析 (`references/female-types.md`)
**底层理论**: 进化心理学（择偶策略理论、亲代投资理论）
- 女性分类体系（按性格、价值观、社交模式）
- 白富美人设识别（如何识别表面包装 vs 真实品质）
- 顶美晋升图谱（理解女性的社交层次进阶）
- 社交软件女性类型识别（牵手/积目/探探等平台用户画像）
- **预计篇幅**: 800-1200 字

#### 2. 个人价值建设 (`references/value-building.md`)
**底层理论**: 社交动力学（社会价值理论、信号传递理论）
- 外形吸引力构建（穿搭、发型、健身、气质）
- 社交媒体展示策略（朋友圈/小红书等）
- 生活方式升级（兴趣、社交圈、经济能力）
- 社交圈层突破（如何进入更高质量的社交圈）
- **预计篇幅**: 800-1200 字

#### 3. 沟通与聊天策略 (`references/communication.md`)
**底层理论**: 行为经济学（框架效应、损失厌恶）、冷读心理学
- 冷读技巧（快速识人）
- 聊天节奏控制（推拉、断联、价值输出）
- 情绪价值输出（幽默、共情、引导）
- 社交软件话术（开场、维护、邀约）
- **预计篇幅**: 800-1200 字

#### 4. 约会实战技巧 (`references/dating-practice.md`)
**底层理论**: 依恋理论、社交心理学（相似性吸引效应、曝光效应）
- 约会流程设计（首次约会到关系确立）
- 搭讪技巧与实战
- 肢体语言与微表情
- 场景选择与环境利用
- 各阶层脱单策略
- **预计篇幅**: 800-1200 字

## 内容边界

- **包含**: 基于人性规律和社会现实的恋爱指导、真诚交往策略、个人成长建议
- **不包含**: PUA 操控技术、欺骗性策略、不尊重女性的内容
- **核心价值**: 帮助用户理解人性、提升自我、建立健康的恋爱观

### Do / Don't 示例

| Do | Don't |
|----|-------|
| "她不回你消息不是因为她忙，而是你在她的优先级里不够高——接受这个现实，然后提升自己" | "教你用5个话术让她秒回，操纵她的注意力" |
| "搭讪的核心是展示真实的自信，不是伪装成另一个人" | "假装是富二代/海归来骗取关注" |
| "理解女性的择偶心理，帮助你找到更匹配的伴侣" | "教你如何'拿下'某个特定的女生" |

## 风险与缓解

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 梵公子内容版权 | IP 纠纷 | 仅使用公开信息和理论总结，不直接复制付费课程内容 |
| 内容边界模糊 | 产出不当建议 | 在 SKILL.md 中硬编码内容边界规则 |
| B站反爬措施 | 字幕提取失败 | 已定义回退策略（见上文） |
| Skill 知识密度过高 | 上下文溢出 | 使用 references/ 按需加载，SKILL.md < 500 行 |

## 实施策略

### 阶段 1: 内容采集
- 搜索梵公子社会学的公开内容精华
- 尝试提取 B 站视频字幕（备选：社区笔记搜索）
- 收集心理学理论框架

### 阶段 2: 知识提炼
- 将采集内容按 4 大模块结构化
- 交叉验证：每个知识点至少有 2 个独立来源确认
- 融合心理学理论作为底层支撑

### 阶段 3: Skill 构建
- 使用 skill-creator 的 init_skill.py 初始化 Skill
- 编写 SKILL.md 主文件（人格 + 策略 + 索引）
- 编写 references/ 下的 4 个知识文件

### 阶段 4: 打磨交付
- 用验收测试题测试 Skill 效果
- 优化 AI 人格一致性
- 使用 package_skill.py 打包交付

## 成功标准

1. AI 能以犀利直接的语气回答男性择偶问题
2. 覆盖 4 大知识模块的常见场景
3. Skill 可直接安装使用（开箱即用）
4. 内容基于公开信息和学术理论，无版权问题
5. 通过 5 个验收测试中的 4 个以上
