# 兼容性分析算法说明

详细解释 love-skill 如何计算配对兼容性评分。

---

## 核心算法框架

### 总体评分公式

```
综合兼容性评分 = 
    MBTI权重(0.15) × MBTI评分 +
    爱语权重(0.2) × 爱语评分 +
    沟通权重(0.2) × 沟通评分 +
    价值观权重(0.2) × 价值观评分 +
    情感权重(0.15) × 情感评分 +
    潜力权重(0.1) × 发展潜力评分

最终范围: 0-100
```

---

## 1. MBTI 匹配度评分（权重 15%）

### MBTI 相似度矩阵

每个维度单独评分：

#### E-I（外向-内向）
| 配对 | 评分 | 说明 |
|------|------|------|
| E-E / I-I | 10 | 完全相同 |
| E-I / I-E | 5 | 互补但需协商 |

#### S-N（感觉-直觉）
| 配对 | 评分 | 说明 |
|------|------|------|
| S-S / N-N | 10 | 完全相同 |
| S-N / N-S | 6 | 信息处理方式不同 |

#### T-F（思考-情感）
| 配对 | 评分 | 说明 |
|------|------|------|
| T-T / F-F | 10 | 完全相同 |
| T-F / F-T | 7 | 决策方式不同，易互补 |

#### J-P（判断-知觉）
| 配对 | 评分 | 说明 |
|------|------|------|
| J-J / P-P | 10 | 完全相同 |
| J-P / P-J | 6 | 生活方式差异大 |

### 加权求和

```
MBTI评分 = (E_I_score × 0.2 + S_N_score × 0.3 + 
           T_F_score × 0.25 + J_P_score × 0.25)
```

### 互补潜力调整

```
if 配对显示高互补潜力:
    MBTI评分 += 5 (up to 15)
```

## 2. 爱情语言匹配（权重 20%）

### 五种爱语评分

每种爱语 1-10 分各自评分：

```
1. 肯定言语 (Words of Affirmation)
2. 精神时刻 (Quality Time)
3. 接受礼物 (Receiving Gifts)
4. 服侍行为 (Acts of Service)
5. 身体接触 (Physical Touch)
```

### 匹配度计算

```python
def calculate_love_language_match(person_a_languages, person_b_languages):
    scores = []
    for lang in ['affirmation', 'quality_time', 'gifts', 'service', 'touch']:
        score_a = person_a_languages[lang]  # 1-10
        score_b = person_b_languages[lang]  # 1-10
        
        # 计算相似度
        difference = abs(score_a - score_b)
        lang_match = 10 - (difference * 0.5)
        
        scores.append(lang_match)
    
    # 互补性奖励
    if high_complementary_potential:
        scores = [min(s + 2, 10) for s in scores]
    
    return sum(scores) / 5
```

### 得分范围

- 0-3：完全不匹配（需要大量沟通）
- 4-6：部分匹配（可协调）
- 7-8：高度匹配（容易理解）
- 9-10：完美匹配（天作之合）

## 3. 沟通风格兼容性（权重 20%）

### 评估维度

#### 沟通频率
```
频繁 (daily) vs 偶尔 (weekly):
  差异评分 = 5 (中等差异，需协商)
  
频繁 vs 很少 (monthly):
  差异评分 = 2 (高风险)
  
类似频率:
  评分 = 9
```

#### 沟通深度
```
深度 vs 浅层:
  评分 = 5 (可互补，但需理解)

相同深度:
  评分 = 9
```

#### 表达方式
```
直接 vs 委婉:
  评分 = 4 (容易误解)

相同方式:
  评分 = 9
```

#### 冲突处理
```
对抗型 vs 回避型:
  评分 = 3 (高冲突风险)

协作型 + 协作型:
  评分 = 10 (理想)
```

### 综合评分

```
沟通评分 = (频率匹配度 × 0.3 + 
           深度匹配度 × 0.3 + 
           表达方式匹配 × 0.2 + 
           冲突处理兼容性 × 0.2)
```

## 4. 生活价值观一致性（权重 20%）

### 关键评估领域

| 领域 | 权重 | 说明 |
|------|------|------|
| 人生目标 | 25% | 职业、家庭、旅行等 |
| 财务观念 | 20% | 消费、储蓄、投资 |
| 家庭观 | 20% | 对伴侣、子女的期待 |
| 生活方式 | 20% | 社交频率、娱乐偏好 |
| 信念/宗教 | 15% | 基础信仰和价值观 |

### 计算方法

```
对每个领域：
  一致性评分 = (1 - 意见差异度) × 10
  
意见差异度：
  - 0：完全一致 (得10分)
  - 0.1-0.3：基本一致 (得7-9分)
  - 0.3-0.7：有分歧但可协商 (得3-6分)
  - 0.7-1.0：根本不同 (得0-2分)

最终评分 = Σ(领域评分 × 领域权重)
```

## 5. 情感模式兼容性（权重 15%）

### 依恋类型匹配矩阵

```
        安全型  焦虑型  回避型  恐惧回避型
安全型  +++    ++     ++     +
焦虑型   ++     +      -      --
回避型   ++     -      ±      --
恐惧回避 +      --     --     -
```

得分对照：
- `+++` = 10（理想搭配）
- `++` = 8（良好兼容）
- `+` = 5（可协调）
- `±` = 4（需努力）
- `-` = 2（高风险）
- `--` = 0（难度大）

### 情感表达兼容性

```
评估维度：
1. 表达爱意的方式
2. 处理冲突的方式
3. 寻求支持的方式
4. 情感脆弱时的反应

相同 → 9分
互补 → 7分
差异大 → 4分
冲突 → 1分
```

### 加权求和

```
情感评分 = 依恋匹配度 × 0.5 + 表达兼容性 × 0.5
```

## 6. 发展潜力评分（权重 10%）

### 潜力因素

```
1. 学习能力
   - 双方都愿意学习 → +3
   - 一方愿意 → +1
   - 都不愿意 → -2

2. 冲突解决能力
   - 都擅长 → +3
   - 一方擅长 → +1
   - 都不擅长 → -2

3. 自我觉察
   - 都高度自知 → +2
   - 一方自知 → +1
   - 都缺乏 → 0

4. 成长意愿
   - 都想长大改变 → +2
   - 一方想 → +1
   - 都满足现状 → 0

5. 爱的深度
   - 都深度投入 → +2
   - 一方深度投入 → +1
   - 都浅尝 → 0
```

### 潜力评分

```
基础评分 = 5（中立）

潜力加成 = Σ(各因素得分)

最终评分 = 基础评分 + 潜力加成

范围：0-15（clamp to 10后的效果）
```

## 风险预警系统

### 红旗（Risk Flags）

系统会识别以下风险因素：

```
🚩 高风险标志：
  - 依恋类型冲突（焦虑+回避）
  - 沟通频率差异 > 50%
  - 价值观基本矛盾（财务、家庭等）
  - 冲突处理方式完全相反
  - 任一方有明显不安全依恋且无成长意愿

⚠️ 中等风险标志：
  - MBTI 所有维度都相反（全互补）
  - 爱语完全不同
  - 生活方式差异大
  - 沟通频率有差异但可修正

✅ 绿旗（Positive Factors）：
  - 都有成长心态
  - 都尊重差异
  - 都愿意为关系投入
  - 共同价值观基础
```

## 评分案例

### 案例 1：高度兼容（85 分）

```
MBTI: ENFP vs ENFJ (相似 + 互补)
  MBTI 评分: 9/10

爱语: 质量时间 vs 肯定言语 (互补)
  爱语评分: 8/10

沟通: 都外向、沟通频繁（+加深度非常契合）
  沟通评分: 9/10

价值观: 都重视人际关系、都想创业
  价值观评分: 8/10

情感: 安全型 vs 安全型
  情感评分: 9/10

潜力: 都高度自知、都有成长意愿
  潜力评分: 9/10

综合：0.15×9 + 0.2×8 + 0.2×9 + 0.2×8 + 0.15×9 + 0.1×9 = 8.5 → 85 分
```

### 案例 2：中等兼容性（55 分）

```
MBTI: INTJ vs ENFP （所有维度相反）
  MBTI 评分: 6/10 (互补但差异大)

爱语: 完全不同
  爱语评分: 5/10

沟通: 频率差异、深度差异
  沟通评分: 5/10

价值观: 人生目标相同但生活方式差异
  价值观评分: 6/10

情感: 一个安全型一个回避型
  情感评分: 5/10

潜力: 都有学习能力但缺乏自知
  潜力评分: 5/10

综合：0.15×6 + 0.2×5 + 0.2×5 + 0.2×6 + 0.15×5 + 0.1×5 = 5.45 → 55 分
```

## 重要限制

⚠️ **本算法的局限**：

1. **基于不完整信息** - 无法完全了解一个人
2. **无法量化爱** - 某些因素无法数学化
3. **忽视时间** - 无法预测关系如何随时间演变
4. **文化差异** - 算法基于西方心理学框架
5. **个体差异** - 同一 MBTI 类型有很大差异
