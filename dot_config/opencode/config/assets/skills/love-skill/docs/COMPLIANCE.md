# 合规与安全说明

## 项目声明

love-skill 是一个供个人娱乐和参考的配对分析工具。本文档说明我们的安全承诺和使用范围。

---

## ✅ 我们的承诺

### 1. 隐私保护

- **本地存储**：所有数据仅存储在你的电脑本地，不上传任何云服务器
- **无第三方分享**：绝不将任何分析结果或原始数据分享给第三方
- **本地控制**：你完全控制何时删除数据
- **无追踪**：不追踪用户的使用行为或数据

### 2. 使用场景限制

✅ **允许的用途**：
- 独自思考和自我认识
- 与相亲对象共同参与（双方知情同意）
- 娱乐和游戏（和朋友们一起玩）
- 学习和研究（了解性格心理学）

❌ **禁止的用途**：
- 未经他人同意分析他人信息
- 用于骚扰、跟踪或隐私侵犯
- 传播他人隐私信息
- 进行医学诊断或心理治疗
- 替代专业婚恋咨询

### 3. 分析的局限性

本工具的分析：

- 🔴 **不能** 100% 预测感情成功或失败
- 🔴 **不能** 替代真实的沟通和相处
- 🔴 **不能** 进行医学诊断
- 🔴 **不能** 替代专业心理咨询
- 🟡 **可能** 有偏见，基于有限信息
- 🟢 **可以** 提供结构化思考框架
- 🟢 **可以** 指出潜在的协调点和挑战
- 🟢 **可以** 建议改善沟通的方式

### 4. 隐私权保障

我们尊重所有涉及人员的隐私权：

- **明确同意**：仅在双方知情且主动同意的情况下分析
- **匿名处理**：所有生成的报告中可以使用代号而不是真名
- **随时删除**：用户可随时删除所有已生成的分析数据
- **数据肖像权**：生成的 Persona 只是参考，不代表真实人物

## 🔐 数据安全措施

### 本地存储

```
所有数据文档存储在：

./matches/{pair-slug}/
  ├── persona-a.md        # Person A 的性格档案
  ├── persona-b.md        # Person B 的性格档案
  ├── compatibility.json  # 兼容性分析数据
  ├── report.md          # 最终配对报告
  └── history/           # 版本历史
```

### 加密备份（可选）

用户可选择启用加密备份：

```bash
# 启用加密备份
python3 tools/backup_matches.sh --encrypt

# 恢复备份
python3 tools/backup_matches.sh --restore --encrypted
```

### 导出格式

支持导出到多种格式：

```bash
# 导出为 JSON（易于备份）
/export-match {slug} --format json

# 导出为 PDF（易于分享）
/export-match {slug} --format pdf

# 导出为加密 ZIP
/export-match {slug} --format encrypted-zip
```

## 💭 伦理指南

### 对参与人员的尊重

1. **知情同意**
   - 在分析前明确告诉对方
   - 解释你为什么想进行这个分析
   - 允许对方拒绝

2. **结果分享的谨慎**
   - 不要强行分享"低兼容性"的结果
   - 不要用分析结果做出非常决定
   - 尊重对方的反应和感受

3. **隐私保护**
   - 不要在背后分析他人
   - 不要分享分析结果给无关的人
   - 删除已不需要的数据

### 对自己的诚实

1. **理性但不冷血**
   - 使用数据框架来思考，但不被数据奴役
   - 记住爱情有理性无法解释的部分

2. **反思而非自我欺骗**
   - 用分析来了解更多，而不是逃避感受
   - 诚实面对分析中显露的真相

3. **理性决断**
   - 基于分析 + 感受 + 直觉来决策
   - 不要因为高兼容性就被迫接受
   - 不要因为低兼容性就放弃是否值得尝试的选择

## 🚨 滥用行为与后果

### 禁止的行为

❌ 未经同意分析他人  
❌ 传播分析结果到社交媒体  
❌ 用分析结果骚扰或威胁他人  
❌ 伪造他人身份进行分析  
❌ 将分析报告用于任何商业目的  

### 如果你意识到滥用

如果你发现有人滥用此工具：

1. **立即停止分享** - 告诉涉及人员发生的情况
2. **删除数据** - 使用 `/delete-match` 删除分析
3. **报告滥用** - 向项目报告不当行为

## 🎓 心理学常识

### 关于性格分析

- **MBTI** 是一个参考框架，不是绝对真理
- **性格** 会随着时间和经历而改变
- **依恋类型** 在安全的关系中可能改变
- **兼容性** 是动态的，不是静态的

### 健康的爱情观

- 没有"完美匹配"，但有很多"足够好的匹配"
- 爱情需要主动选择和继续投入
- 冲突是正常的，健康关系中冲突是可解决的
- 相处的质量取决于你们的沟通和理解
