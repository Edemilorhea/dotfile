# 聊天记录导出指南

如何安全地导出聊天记录以用于配对分析。

---

## 微信聊天记录导出

### 方法 1：使用 WeChatMsg（推荐）

**优点**：功能完整、支持图片、支持批量导出

**下载**：https://github.com/LC044/WeChatMsg

**步骤**：

1. 下载并安装 WeChatMsg
2. 打开应用，点击"导出"
3. 选择要导出的聊天对话
4. 选择导出格式（推荐 CSV 或 JSON）
5. 导出完成后看到文件路径

**导出格式**：支持 TXT、HTML、JSON、CSV

**文件大小**：取决于聊天量，通常 1-100 MB

### 方法 2：使用留痕

**优点**：界面友好、导出速度快

**下载**：https://qwerty123.github.io/pyZhiyuan/

**步骤**：类似 WeChatMsg，按提示导出即可

### 方法 3：手动导出微信记录

如果无法使用第三方工具：

1. 打开微信
2. 找到要导出的聊天
3. 长按聊天头像 → 查看聊天记录
4. 点击右上角 ⋮ → 转发整个聊天记录
5. 选择 "聊天记录" → 发送给自己或存为文件

**缺点**：只能导出 7 天内的记录、不支持图片

## QQ 聊天记录导出

### 方法 1：QQ 消息管理器

**官方工具**，安全可靠

**步骤**：

1. 打开 QQ → 主菜单 → 设置
2. 左侧栏 → "聊天记录"
3. 勾选要导出的聊天
4. 点击"导出" → 选择保存位置

**格式**：.mht（网页归档）或 .txt

### 方法 2：使用 PyQtQQ

开源工具，导出功能强大

**下载**：https://github.com/txdywy/QQExport

**步骤**：按工具说明操作

**格式**：支持 JSON、HTML、CSV

### 方法 3：截图 + 手工整理

如果其他方法不可行：

1. 找到关键对话
2. 逐条截图
3. 放入文本文件或 Word
4. 上传给 Claude Code

**缺点**：耗时、不完整

## 照片元数据导出

### 照片 EXIF 信息

如果想保留照片的拍摄地点、时间等信息：

**方法 1：使用在线工具**

访问 https://www.verexif.com/ 或类似网站，上传照片查看 EXIF。

**方法 2：使用命令行**

```bash
# 如果已安装 ImageMagick
identify -verbose photo.jpg | grep -E "Date|GPS|Camera"

# 或使用 exiftool
exiftool photo.jpg
```

**方法 3：直接上传照片**

love-skill 会自动提取 EXIF 信息。

## 安全导出建议

### ✅ 做这些

- ✅ 在自己的电脑上导出
- ✅ 核实包含的内容是你想分享的
- ✅ 删除其他人的隐私信息（如其他人的聊天记录片段）
- ✅ 删除不相关的敏感信息（如银行账号、密码等）
- ✅ 使用加密文件存储敏感导出

### ❌ 不要这些

- ❌ 让他人代你导出
- ❌ 将原始导出文件分享给他人
- ❌ 使用在线工具导出（可能被记录）
- ❌ 导出包含其他人隐私的内容而不告知他们
- ❌ 将导出结果上传到云存储

## 导出文件格式说明

### 支持的格式

| 格式 | 优点 | 缺点 |
|------|------|------|
| TXT | 简洁、通用 | 丧失格式信息 |
| JSON | 结构清晰、易解析 | 需要专业工具 |
| CSV | 易导入 Excel | 不支持复杂内容 |
| HTML | 保留排版 | 文件较大 |
| MHT | 完整保留、支持图片 | 兼容性一般 |

### 推荐导出策略

1. **聊天记录** → JSON 或 HTML（保留上下文）
2. **朋友圈** → HTML（保留排版）
3. **照片** → 原始 JPG/PNG（保留 EXIF）
4. **文本描述** → TXT 或 Markdown

## 导出后的处理

### 隐私脱敏

在导出后，建议进行脱敏处理：

```python
# 示例：移除电话号码
import re

def remove_phone_numbers(text):
    return re.sub(r'1[3-9]\d{9}', '[PHONE]', text)

def remove_ids(text):
    return re.sub(r'\d{15,18}', '[ID]', text)
```

### 备份导出文件

```bash
# 创建备份
cp -r exports/ exports_backup_$(date +%Y%m%d)/

# 加密备份（可选）
tar czf exports_backup.tar.gz exports/
gpg --symmetric exports_backup.tar.gz
```

## 常见问题

**Q: 导出的文件会被自动上传吗？**  
A: 不会。所有文件仅在你本地处理。

**Q: 可以导出他人的聊天记录吗？**  
A: 技术上可以，但在没有同意的情况下这样做违反隐私。

**Q: 导出后我可以删除吗？**  
A: 当然可以。建议导出后立即删除原始文件，仅保留脱敏版本。

**Q: 导出失败了怎么办？**  
A: 尝试另一种导出工具，或手工整理关键对话。
