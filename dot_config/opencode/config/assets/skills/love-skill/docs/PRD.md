# 产品需求文档（PRD）

## 执行摘要

**产品名称**：love-skill  
**版本**：1.0.0  
**发布日期**：2024 年  
**目标用户**：相亲人群、需要性格兼容性分析的用户  
**核心价值**：通过科学框架帮助用户更理性地认识相亲对象，判断性格兼容性

---

## 产品概述

### 问题陈述

在现代相亲中，用户面临：
- 认识时间有限，无法充分了解对方
- 聊天中的第一印象可能不准确
- 缺乏科学框架来评估兼容性
- 性格差异导致持续摩擦，但不知道如何调整

### 解决方案

love-skill 是一个基于心理学原理的配对分析工具，通过：

1. **深层数据收集**
   - 聊天记录分析（说话风格、沟通习惯）
   - 社交媒体分析（生活态度、价值观）
   - 照片 EXIF 分析（生活方式线索）
   - 用户直接描述（主观印象）

2. **多维度评估**
   - MBTI 类型匹配（15% 权重）
   - 爱的五种语言匹配（20% 权重）
   - 沟通风格兼容性（20% 权重）
   - 生活价值观一致性（20% 权重）
   - 情感模式协调度（15% 权重）
   - 发展潜力评估（10% 权重）

3. **智能报告生成**
   - 量化兼容性评分（0-100）
   - 定性深度分析
   - 实用相处建议
   - 风险预警和机遇识别

## 目标用户

### 主要用户群

1. **初入相亲市场的年轻人**（25-35 岁）
   - 需求：快速了解对方是否合适
   - 痛点：害怕投入后才发现不适配

2. **理性型相亲者**（各年龄）
   - 需求：用数据支持感受
   - 痛点：感到困惑或不确定

3. **经历过关系困扰的用户**
   - 需求：理解性格冲突的根源
   - 痛点：不知道是否该继续或如何改善

### 次要用户群

- 心理学爱好者（学习性格理论）
- 关系顾问（客户教育工具）
- 娱乐性用户（朋友圈测试）

## 核心功能

### 功能 1：信息收集

**触发方式**：用户运行 `/match-maker` 命令

**流程**：
1. 收集 Person A 信息（代号、基本信息、性格描述）
2. 收集 Person B 信息（同上）
3. 提供原材料导入选项（聊天记录、朋友圈、照片、测试结果等）
4. 确认所有信息

**验证规则**：
- 代号必填，不能为空
- 代号同一配对内不能重复
- 文件格式限制（TXT、JSON、HTML、CSV）
- 文件大小限制（单个 ≤ 50MB，总计 ≤ 500MB）

### 功能 2：数据解析

**支持的数据源**：

| 数据源 | 格式 | 解析工具 | 提取内容 |
|------|------|--------|---------|
| 微信 | TXT/JSON/HTML | wechat_parser.py | 消息时间戳、发送者、内容、频率 |
| QQ | TXT/JSON/MHT | qq_parser.py | 同上 |
| 朋友圈 | HTML/PNG/TXT | social_parser.py | 文案、时间、互动模式 |
| 照片 | JPG/PNG | photo_analyzer.py | EXIF、拍摄地点、时间 |
| 测试结果 | TXT/IMAGE | manual.py | 性格类型数据 |

**数据脱敏**：
- 自动过滤电话号码、身份证号
- 可选加密存储
- 用户可手工删除敏感信息

### 功能 3：Persona 生成

**输出格式**：Markdown 文档

**内容结构**：
- Layer 0：硬规则（数据限制）
- Layer 1：身份（基本信息、类型）
- Layer 2：说话风格（习惯、特色）
- Layer 3：情感模式（依恋、爱语）
- Layer 4：价值观（优先级、生活方式）
- Layer 5：潜力（优势、挑战、成长空间）

**生成方式**：基于导入数据 + 心理学模型 + Claude AI 分析

### 功能 4：兼容性分析

**计算引擎**：
- 基于《docs/ALGORITHM.md》中的公式
- 六个维度独立评分（0-10），然后加权求和
- 最终得分范围：0-100

**输出格式**：JSON 数据 + Markdown 详细分析

**包含内容**：
- 各维度评分详解
- 优势互补分析
- 潜在挑战识别
- 红旗与绿旗警告
- 改善建议

### 功能 5：报告生成

**输出格式**：美观的 Markdown 报告

**使用场景**：
- 自我思考
- 与伴侣讨论
- 分享给信任的朋友
- 用作心理咨询师的补充

**报告内容**：
- 快速导览（1 句总结）
- 核心兼容性评分
- MBTI 配对故事
- 爱情语言指南
- 沟通策略建议
- 三阶段相处建议
- 红旗与绿旗清单
- 总结与未来蓝图

### 功能 6：版本管理

**功能**：
- 自动备份每次更新
- 查看分析历史
- 回滚到旧版本

**触发方式**：
- 用户可通过 `/update-match` 手动更新
- 支持增量更新（仅更新新信息）

### 功能 7：数据管理

**支持的操作**：
- `/list-matches`：列出所有配对
- `/delete-match {slug}`：删除配对及其数据
- 导出为 JSON / PDF / 加密备份

## 用户体验流程

### 首次使用流程

```
用户输入
  ↓
/match-maker 命令触发
  ↓
【第 1-2 分钟】收集双方基本信息（6 个问题）
  ↓
【第 3-4 分钟】呈现原材料导入选项
  ↓
【第 5-10 分钟】用户上传/输入原材料
  ↓
【第 11-15 分钟】系统处理和分析
  • Persona 生成（Claude AI）
  • 兼容性计算
  • 报告生成
  ↓
【第 16 分钟】呈现最终报告
  ↓
用户可查看/分享/更新
```

### 持续使用流程

```
查看已有配对
  ↓
/list-matches
  ↓
选择配对进行操作：
  • /{pair-slug} → 查看完整报告
  • /{pair-slug}-detail → 深度分析
  • /update-match {pair-slug} → 更新信息
  • /delete-match {pair-slug} → 删除
```

## 安全与隐私

### 数据安全措施

1. **本地存储**
   - 所有数据存储在用户电脑
   - 不上传任何服务器或云服务
   - 用户完全控制删除权

2. **隐私保护**
   - 自动过滤敏感个人信息（电话、身份证）
   - 支持匿名化（使用代号而非真名）
   - 可选加密备份

3. **访问控制**
   - 仅用户在自己电脑上可访问
   - Claude Code 中的 Skill 仅该用户可见
   - 不存储在云端

### 合规说明

详见 [docs/COMPLIANCE.md](love-skill/docs/COMPLIANCE.md)

关键承诺：
- ✅ 仅用于娱乐和个人参考
- ✅ 不用于骚扰或隐私侵犯
- ✅ 尊重所有涉及人员的隐私
- ✅ 结果不构成真实建议
