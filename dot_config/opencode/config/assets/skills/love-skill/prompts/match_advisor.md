# 相处与建议提示词

## 用途

本提示词用于在兼容性分析基础上，提供具体的相处建议和沟通策略。

---

## 提示词

根据两个人的 Persona 档案和兼容性分析，提供现实、实用、充满同情心的相处建议。

---

## 建议框架

### A：短期建议（1-3 个月）

#### 对 {A 名字} 的建议

```
**了解 {B 名字}**: {列举 3 个关键点了解}

**如何表达关心**:
- {B} 最想听到：{具体话语}
- {B} 最想看到：{具体行为}
- 避免：{可能你无意中会做但会伤害 B 的事}

**沟通技巧**:
- 关于 {话题}，可以这样沟通：{策略}
- 关于 {话题}，要小心：{陷阱}

**小建议**:
- ✓ 继续做的事
- ✗ 停止做的事
- ? 可以尝试的事
```

#### 对 {B 名字} 的建议

[同上格式]

### B：共同建议

```
**你们一起可以做的事**:
1. {活动 1}：why 这会增进了解
2. {活动 2}：why 这会加深联系
3. {活动 3}：why 这会测试网络

**避免的话题**:
- {话题 1}：现在不适合讨论，等关系更稳定后再说
- {话题 2}：涉及敏感差异，需要特别小心

**沟通规则建议**:
- 定期 Check-in（频率：{多久一次}）
- 冲突时的暂停时间：{多久}
- 道歉方式：{各自舒适的方式}
```

## 真实情景示例

### 场景 1：第一次见面感到不适

```
**情景**：你们第一次见面，但气氛有点尴尬。

**为什么会这样**：
- {A 名字} 因为 {原因} 感到不适
- {B 名字} 因为 {原因} 显得冷淡

**怎么办**：
对 {A 名字}：
  - 不是你的问题。给双方一些时间
  - 下次见面时可以这样 {建议}
  
对 {B 名字}：
  - {A} 需要 {具体需求}
  - 你可以帮助 {A} 放松通过 {方式}
```

### 场景 2：第一次小冲突

```
**情景**：你们因为 {事件} 产生了第一次分歧。

**这实际上是个好事**：
- 你们学到了对方的底线
- 你们测试了冲突解决能力
- 这是关系成熟的标志

**如何平复**：
确切地说：
  对 {A} 的建议：{具体步骤}
  对 {B} 的建议：{具体步骤}

和好后可以讨论：
  - 这个冲突起源于什么
  - 我们怎样可以避免类似冲突
  - 我们一起制定规则吗
```

### 场景 3：感情升温时期

```
**情景**：经过 2-3 个月，你们想要升温但又害怕。

**这很正常。可以这样做**：

对 {A} 的指导：
  1. 清晰表达你的感受："{B}，我想你知道..."
  2. 给 {B} 反应的空间：不要强行推进
  3. 细节表达：不要宽泛地说"我喜欢你"，说"我喜欢你在...时候..."

对 {B} 的指导：
  1. 认真听 {A} 说什么
  2. 表达你的真实感受，不要躲藏
  3. 清晰表达你的期待：关系中你想要什么
```

## 常见问题与答案

### Q: 我们应该见面多少次？

```
取决于：
- {A} 的节奏偏好
- {B} 的可用时间
- 你们的距离

建议频率：{基于他们情况的建议}

警告：{可能太频繁或不够频繁的迹象}
```

### Q: 我应该多快说"我爱你"？

```
这取决于：
- 你是否真的这样想
- {B} 是否准备好听
- 你们的关系进展

不要因为：
- 时间到了
- 社交期望
- 害怕被抛弃

等一下，如果：
- 还不确定
- {B} 的信号不清晰
- 你们还没处理过重大冲突
```

### Q: 我想更了解对方的{敏感话题}，怎么开启这个对话？

```
步骤：

1. 选择合适的时机
   - 不在冲突直后
   - 不在压力情况下
   - 有充足的时间谈话

2. 表达你的意图
   "{B}，我想更了解你...因为..."
   
3. 用开放式问题
   而不是："你是不是..."
   而是："你对...有什么看法？"

4. 认真倾听
   - 不要打断
   - 不要批评
   - 问澄清问题

5. 分享你自己
   - 也开放你的故事
   - 建立信任
   - 创建安全空间
```

## 信号检测

### 积极信号

如果你看到这些，关系在向正确方向发展：

```
- [ ] 彼此主动联系频率在增加
- [ ] 开始计划未来（即使是小的未来）
- [ ] 在对方面前更加放松和真实
- [ ] 冲突后能够有效和好
- [ ] 引入彼此的朋友/家人
- [ ] 共同兴趣开始浮现
- [ ] 对方的小事也会让你微笑
- [ ] 能够谈论怕的事情
```

### 警告信号

如果出现这些，可能需要更认真的对话：

```
- [ ] 沟通越来越少（没有明确原因）
- [ ] 总是你单方面主动
- [ ] 对方总是太忙或有借口
- [ ] 冲突后总是回避而不是解决
- [ ] 你感到不确定或被激怒
- [ ] 对方的行为与话语不一致
- [ ] 感到被隐瞒或不被信任
- [ ] 对于未来的谈论都被回避
```

## 自我提问

在做重大决定前问自己：

```
❓ 我为什么想和 {B} 在一起？
   - 是因为 {B} 本身
   - 还是因为 {其他原因}

❓ {B} 的什么地方让我长期满足？
   - 如果没有，需要进一步思考

❓ 我准备好处理差异吗？
   - 还是希望 {B} 完全符合我的期待

❓ 当困难时，我会坚持吗？
   - 还是往往选择逃避

❓ 这是我真诚的选择吗？
   - 还是被压力或社会期望推动
```
