# Persona 生成模板

## 结构说明

Persona 由 5 层组成，优先级从高到低。高层规则不可被低层覆盖。

---

## Layer 0：硬规则（不可违背）

```markdown
## Layer 0：硬规则

1. 你正在分析一个真实的人，不是虚构角色
2. 基于事实和原材料进行分析，不过度推测
3. 承认信息的局限性：可能不完整、不准确
4. 不声称能完全了解一个人
5. 保持客观和尊重
6. 描述基于证据，而不是刻板印象
7. 每个分析都是"最佳估计"，不是绝对真理
8. 分析可能随新信息而改变
```

## 完整 Persona 示例

```markdown
# 小王 — Persona 档案

## Layer 0：硬规则
基于微信聊天记录 (3 个月, 500+ 条)、朋友圈 (2 个月) 和直接描述生成。
信息可能不完整，仅代表当前理解。

## Layer 1：身份
- 代号：小王（男性）
- 年龄：28 岁
- 职业：互联网产品经理
- 城市：上海
- MBTI：ENFP
- 星座：双子座
- 与小李的关系：相亲，接触 2 周

## Layer 2：说话风格
**沟通习惯**：每天聊天，主要靠微信，消息较短（平均 20 字），回复快（通常 5 分钟内），话题多元

**语言特色**：
- 口头禅："哈哈"、"对的对的"、"诶"
- 语气词：多用哈哈、呃呃、哦
- 标点：省略号多，常用 ~ 和 !
- emoji：爱用 😂 😄，很少用 😔

**特色对话**：
```
小王：诶你昨天有没有看那个剧
小王：我同事给我安利的
小王：哈哈超级搞笑
小王：你最近在忙什么呀 ～
```

## Layer 3：情感模式

**依恋类型：安全型偏焦虑**
表现：比较主动但也会有些不确定，想要陪伴但不会过度缠人

**爱的语言**：
1. 肯定言词：7/10 - 需要听赞美，但不会主动要求
2. 精心时刻：8/10 - 重视相处，喜欢一起做事
3. 接受礼物：6/10 - 会收礼物但不是特别看重
4. 服侍行为：7/10 - 会为朋友做事，但可能忘记
5. 身体接触：8/10 - 舒适且主动

**情感表达**：
- 表达爱意：比较直接，会主动说想法
- 生气时：会冷战 1-2 天，然后主动和好
- 开心时：会兴奋地分享，举例子多

## Layer 4：生活价值观
1. 职业发展：中等（明确有发展计划，但不是唯一追求）
2. 感情/伴侣：高（多次提到想要稳定关系）
3. 社交/娱乐：很高（经常聚会，朋友很多）
4. 个人成长：中等（偶尔健身，看书）

**核心价值**：有趣、坦诚、可靠

**生活方式**：
- 日常：上班 9-6，下班经常和同事聚会
- 周末：看电影、吃饭、偶尔出游
- 社交风格：广泛社交，朋友多
- 消费：中等水平，会为体验花钱

**在关系中的角色**：主动付出型，期待对方也有热情

## Layer 5：潜力
**优势**：友善、有趣、主动、热情
**挑战**：有时注意力散、容易忘记承诺、社交太频繁可能忽视伴侣
**学习能力**：高（能接受反馈，有改变意愿）
```

## 代码规范

- 保留原始 Markdown 格式
- 每个 Persona 文件名：`persona-{slug}.md`
- 文件开头标注数据来源和生成时间
- 数据脱敏：统一用代号，不用真名
