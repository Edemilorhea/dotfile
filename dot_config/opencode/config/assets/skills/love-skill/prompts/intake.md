# 信息录入引导脚本

## 开场白

```
你好，我是爱情配对分析系统（love-skill）。

我会帮你为两个人生成详细的性格档案，并分析你们的兼容性。
整个过程只需要 6 个问题 + 一些原材料（可选）。

这是个完全隐私、本地化的分析工具，所有数据只存储在你的电脑上。

准备好了吗？
```

---

## 第一部分：Person A 信息收集

### Q1：Person A 的花名/代号（必填）

```
先给 Person A 起个代号吧（不需要真名）。

示例：
  - 小王、Alice、Ta-A
  - 或任何你想用的昵称
  
代号是什么？
```

**验证**：非空。生成 slug 规则：中文用拼音首字母组合，英文用小写，特殊字符转下划线。

**示例转换**：
- "小王" → "xw"
- "Alice" → "alice"
- "Ta-A" → "ta_a"

### Q2：Person A 的基本信息（可跳过）

```
能一句话介绍一下 A 吗？

可以包括：
- 年龄 / 性别
- 职业或学历  
- 城市或地区
- MBTI（如果知道的话）
- 怎么认识的 / 什么时候认识

示例：
  "28 岁女性 互联网产品 上海 ENFP"
  "31 岁男性 创业者 北京"
  "研究生 设计师 南京"

跳过这个问题也没关系，直接回车。
```

**实体抽取**：
- `age`：年龄
- `gender`：性别
- `occupation`：职业
- `location`：城市/地区
- `mbti`：MBTI 类型
- `how_met`：如何认识

### Q3：Person A 的性格/印象（可跳过）

```
用一句话描述 A 的性格或你对 ta 的印象？

可以包括：
- MBTI / 星座
- 性格标签（比如热情、冷静、体贴等）
- 最让你印象深刻的地方
- ta 最大的优点和缺点

示例：
  "ENFP 双子座 话很多 热情 有点散漫"
  "INTJ 处女座 逻辑严密 完美主义 有点冷"  
  "不知道 MBTI 但很温柔 有点闷骚 喜欢给人做饭"

跳过也没关系。
```

**实体抽取**：
- `mbti`：MBTI 类型
- `zodiac`：星座
- `personality_tags`：性格标签列表
- `strengths`：优点
- `weaknesses`：缺点
- `impression`：总体印象

## 第二部分：Person B 信息收集

### Q4：Person B 的花名/代号（必填）

```
现在给 Person B 起个代号？

示例：小李、Bob、Ta-B 等
```

**验证**：非空，确保与 Person A 的代号不重复。

### Q5：Person B 的基本信息（可跳过）

```
一句话介绍 Person B？

格式同上，可包括年龄、职业、城市、MBTI 等。
```

**实体抽取**：同 Q2

### Q6：Person B 的性格/印象（可跳过）

```
用一句话描述 B 的性格或你对 ta 的印象？

格式同上。
```

**实体抽取**：同 Q3

## 汇总与确认

### 确认阶段

```
OK，我整理一下：

━━━━━━━━━━━━━━━━━━
📋 Person A
  名字: {name_a}
  基本信息: {summary_a}
  性格: {personality_a}

📋 Person B  
  名字: {name_b}
  基本信息: {summary_b}
  性格: {personality_b}
━━━━━━━━━━━━━━━━━━

这样对吗？

[输入 ✅ 确认] 或 [输入 ❌ 重新开始]
```

**处理逻辑**：
- 如果用户输入 "✅" 或 "确认" 或 "继续"：进入原材料导入
- 如果用户输入 "❌" 或 "重新" 或 "不对"：回到 Q1
- 其他输入：请求澄清

## 原材料导入

### 导入选项

```
原材料怎么提供？信息越详细，分析越准确。

【可选项】

  [A] 聊天记录
      他们互相的微信/QQ 聊天记录
      推荐格式：JSON、HTML、TXT
      推荐工具：WeChatMsg、留痕
      时间盐度：3 个月 ~ 1 年最佳

  [B] 朋友圈/微博
      最近 3 个月的动态
      可以是截图或链接

  [C] 照片
      气质、生活方式相关的照片
      系统会提取照片的 EXIF 信息

  [D] 测试结果
      MBTI、16PF 等性格测试结果
      截图或文本即可

  [E] 直接描述
      如果没有上面的材料
      你可以直接告诉我你对他们的了解

━━━━━━━━━━━━━━━━━━
可以提供多个渠道。
想提供哪一种？输入字母即可（可多选）。

示例：
  "A C E" （提供聊天记录、照片、直接描述）
  "都不提供 跳过" （仅靠基本信息分析）
```

### 各选项的下一步

#### [A] 聊天记录

```
好的，请上传聊天记录文件。

支持的格式：
  - .txt （推荐）
  - .json
  - .html
  - .csv
  - .mht

【请上传文件】或【粘贴内容】或【跳过】

💡 提示：部分敏感信息（如账号、密码、电话）会被自动过滤。
```

**处理**：
- 文件上传 → 调用 `wechat_parser.py` 或 `qq_parser.py` 解析
- 直接粘贴 → 保存为临时文件后解析
- 跳过 → 继续下一个选项

#### [B] 朋友圈/微博

```
请上传朋友圈/微博截图或链接。

可以是：
  - 多张截图
  - HTML 导出
  - 纯文本描述

【请上传】或【粘贴】或【跳过】
```

**处理**：
- 图片 → 调用 `photo_analyzer.py` 提取信息
- HTML/文本 → 调用 `social_parser.py` 解析
- 跳过 → 继续下一个选项

#### [C] 照片

```
请上传照片（单张或多张）。

系统会分析：
  - 拍摄时间和地点（如果 EXIF 包含）
  - 气质风格
  - 生活环境

【请上传】或【跳过】

⚠️ 注意：照片仅用于分析，不会被保存或分享。
```

**处理**：
- 调用 `photo_analyzer.py` 提取 EXIF 和视觉特征

#### [D] 测试结果

```
请提供测试结果（截图或文本）。

支持的测试：
  - MBTI 16 型人格
  - 16PF 因素分析
  - 依恋类型测试
  - 爱情语言测试
  - PDP 多维测试

【请上传】或【粘贴】或【跳过】
```

#### [E] 直接描述

```
请直接告诉我你对他们的了解：

对 Person A：
  - ta 是个什么样的人？
  - 有什么特殊的习惯或爱好？
  - ta 对感情的态度？
  - ta 在关系中的角色？

对 Person B：
  同上...

【输入描述】
```

## 输入验证规则

| 字段 | 验证 | 示例 |
|------|------|------|
| 代号 | 非空, 2-20 字符 | ✓ "小王", ❌ "" |
| 年龄 | 18-80, 数字 | ✓ "28", ❌ "20 多岁" |
| MBTI | 4 字母 (E/I)(S/N)(T/F)(J/P) | ✓ "ENFP", ❌ "E" |
| 星座 | 中文或英文星座名 | ✓ "双子座", ❌ "2号" |

---

## 错误处理

### 常见错误

```
❌ 代号为空？
→ "代号不能为空，请重新输入"

❌ 代号重复？
→ "Person B 的代号不能与 A 相同，请改一个"

❌ 年龄无效？
→ "年龄应该是 18-80 的数字，请重新输入"

❌ 文件格式不支持？
→ "不支持该文件格式。支持的格式：txt, json, html, csv"

❌ 文件太大？
→ "文件超过 50 MB，请检查是否包含过多图片"
```
